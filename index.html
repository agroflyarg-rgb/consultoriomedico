📖 Instrucciones Supabase
1
Crear cuenta

Ingresá a supabase.com y registrate gratis.

2
Crear proyecto

New Project → nombre (ej: consultorio-lozina) → región South America (São Paulo).

3
Crear la tabla en SQL Editor
CREATE TABLE consultas ( id uuid DEFAULT gen_random_uuid() PRIMARY KEY, nombre text NOT NULL, apellido text NOT NULL, fecha date NOT NULL, obra_social text, diagnostico text, created_at timestamp with time zone DEFAULT now() ); ALTER TABLE consultas ENABLE ROW LEVEL SECURITY; CREATE POLICY "pub" ON consultas FOR ALL USING (true) WITH CHECK (true);
4
Obtener credenciales

Project Settings → API → copiá Project URL y anon public key.
